# Zero-Day Core

Zero-Day Core is the LOGIC area's breached-mainframe presentation. The stable
`cryo` region identity, category, challenges, captures and scoring remain intact.
The arena and staff selector use the new display name.

The scenery is directly drawn SVG: black glass process modules, sharp data
channels, an exposed memory fracture, scanning access barriers and independently
rotating encryption-seal layers. Acid green, electric cyan, ultraviolet and
hazard orange carry the light. Labels connect the machinery to state, scheduling,
mutual exclusion and race conditions. The rejected pastel scenery and character
drawings have been removed.

| Entity | Identity |
| --- | --- |
| Spectre | Thin asymmetric chrome shell, detached phase panels and scan echoes |
| Rootkit | Low armoured hull, four jointed gripping limbs and a rotating scanning fan |
| Deadlock | Two opposing rigid frames straining around a compressed core, with short mechanical surges |
| Racewire | Narrow chassis, two independently moving signal filaments and intertwined traces |
| Heap Eater | Dark intake block and five contracting memory chambers with illuminated allocation slots |
| Kernel Wraith | Blade chassis and four assembling fragments, with a stepped interference wake |

Effects are cosmetic and retain one clickable core per target. Higher bounties
increase the silhouette and add an Intrusion field of access brackets and signal
ticks. Creature identity is communicated through machinery, movement and signal
patterns. Hover, pause, an open workbench and reduced motion preserve the existing
interaction controls.

The fixed-scale map still pans across a four-by-four world. Scenery is bounded to
48 process modules, eight animated channels and one fracture flow. The entity
renderer retains cached textures (at most 22 shared GPU textures), instanced
moving parts and the existing four-leg solver without adding lights. No image is
generated per frame. The local demo still has ten dummy bugs in each region.

Unit checks cover bounded layouts, family identity, rarity and articulation,
including the Rootkit's fixed hip joints and leg lengths. Browser checks inspect
the actual renderer, cached art, data animation, pausing, mobile layout, panning
and question entry. Production checks exclude preview fixtures from the build.
Physical old-laptop frame rates remain unmeasured.
