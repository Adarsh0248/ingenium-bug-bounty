# Round 1 infrastructure review — historical

This public summary records failure classes and corrections from the finished event. Individual participant source, names, report IDs, per-team adjudication and private host details are not included.

The main review separated admission/queue delay, source compilation errors, true infrastructure uncertainty, original attempt cleanup and scoring effects. Some compiler source diagnostics had been classified as infrastructure failure. The attribution logic and fixtures were corrected; an invalid program did not become eligible for a correct-solution bounty merely because the infrastructure label was wrong.

Manual reports/document answers were reviewed as the originally submitted text. The organiser matched each question/team, checked logic and compiler behavior and checked existing awards before applying any missing earned bounty. General goodwill compensation was handled separately. Original website verdicts, request/source hashes, physical attempts and sporting history were preserved.

Subsequent judge work introduced compile-once case batches and sixteen physical slots with fresh qualified host identities. The final measured peak remained 22.254 seconds for the fifteen-team compiler fixture.
